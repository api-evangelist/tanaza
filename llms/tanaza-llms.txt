# Tanaza

> Tanaza is a hardware-agnostic, cloud-based Wi-Fi management platform (Milan, Italy) for configuring, monitoring, and operating Wi-Fi access points, SSIDs, and networks from one dashboard. It also runs Classic Hotspot, a guest-Wi-Fi / captive-portal product (social login, paid Wi-Fi vouchers, splash pages, analytics). Tanaza exposes three API families and a Push Contact Notifications webhook.

## APIs

- [Tanaza APIs Overview](https://success.tanaza.com/s/article/Tanaza-APIs-Overview): Network Management API, Network Monitoring API, and Application API over the Tanaza Cloud dashboard data set.
- [Network Monitoring API](https://success.tanaza.com/s/article/Network-Status-APIs): read networks/access points (label, MAC address, SSIDs, last-packet timestamp, status), active SSIDs, connected clients, and signal strength (dBm).
- [Push Contact Notifications (Webhooks)](https://success.tanaza.com/s/article/Push-notifications): Tanaza delivers event notifications to a customer-hosted public endpoint via HTTP POST.

## Products

- [Cloud Wi-Fi Management](https://www.tanaza.com/wifi-cloud-management/): centralized cloud management for Wi-Fi access points.
- [Classic Hotspot](https://www.classichotspot.com/): guest Wi-Fi, captive portal, social login, paid Wi-Fi, analytics.
- [Core Features](https://www.tanaza.com/tanaza-features/): full platform feature list.
